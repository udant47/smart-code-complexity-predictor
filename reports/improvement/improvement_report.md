## Notes

- Before = the previous release's configuration re-fitted with the same seed on the same rows; its test macro F1 reproduces the recorded value.
- The test set was used once for the final model; feature and model choices were made by cross-validation.
- The 95% confidence intervals of the before and after test macro F1 overlap (see the evaluation report), so the test-set change alone is not statistically conclusive; the cross-validated gain is the main evidence.
- Static analyzer: Unknown means the pattern is not supported; it is never counted as correct.
